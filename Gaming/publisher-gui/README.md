# 📦 Mission Control — Publisher GUI (`Gaming/publisher-gui`)

<p align="center">
  <img src="../frontend/public/logo.png" width="80" alt="Publisher GUI Logo" />
</p>

The official release publishing and packaging desktop utility for **Mission Control**, built with Electron, Vite, TypeScript, and Tailwind CSS.

---

## ⚡ Key Features

- **🚀 Automated Build & Release Dispatch**: Interface for triggering local builds, NSIS installer creation, and GitHub release uploads.
- **📜 Manifest Synchronization**: Syncs version tags, release notes, and release assets across `version.json` and local manifests.
- **🔑 Credential Isolation**: Secure local storage for signing certificates and upload keys.

---

## 🛠️ Tech Stack

- **Framework**: Electron + Vite
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript

---

## 🚀 Getting Started

### 1. Installation

```bash
cd Gaming/publisher-gui
npm install
```

### 2. Run in Development Mode

```bash
npm run dev
```
